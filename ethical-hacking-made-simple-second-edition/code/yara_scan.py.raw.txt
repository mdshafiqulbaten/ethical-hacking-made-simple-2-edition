  REALITY CHECK

  Real dynamic malware analysis happens inside specialized, fully net‐
  work-isolated sandboxes built and maintained specifically for that
  purpose, often with no outbound internet access at all and exten‐
  sive monitoring, run by analysts trained in that discipline. It is a dis‐

  skills this book covers, and nothing in this chapter is a substitute for
  that infrastructure or training.

Key Takeaways
  Static triage — hash, size, entropy, strings, pattern matching —
  answers most early questions without ever running a file.
  A file's SHA-256 hash is how you track and share its identity with‐
  out handling the file itself.
  A YARA rule's narrowness (what it is written to match) matters as
  much as whether it matches.
  Escalating to dynamic analysis is a handoff to specialized, isolated
  infrastructure, not a next step to take on a general-purpose
  machine.
